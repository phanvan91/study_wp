## 1. Tổng quan Internationalization

### Khái niệm

```
i18n (Internationalization):
  - Viết code SẴN SÀNG để dịch
  - Wrap tất cả strings hiển thị bằng translation functions
  - Là việc của DEVELOPER
  - "i18n" = i + 18 ký tự + n

l10n (Localization):
  - Dịch strings sang ngôn ngữ cụ thể
  - Tạo file .po/.mo cho mỗi ngôn ngữ
  - Là việc của TRANSLATOR
  - "l10n" = l + 10 ký tự + n

Quy trình:
  Developer viết code (i18n)
       ↓
  Tạo file .pot (template)
       ↓
  Translator tạo .po (bản dịch)
       ↓
  Compile thành .mo (binary, dùng runtime)
       ↓
  WordPress load .mo theo ngôn ngữ user chọn
```

### File types

```
.pot (Portable Object Template):
  - Template chứa TẤT CẢ strings cần dịch
  - Tạo tự động bằng WP-CLI hoặc tools
  - Không chứa bản dịch, chỉ chứa strings gốc

.po (Portable Object):
  - File text, chứa bản dịch cho 1 ngôn ngữ
  - Ví dụ: my-plugin-vi.po (tiếng Việt)
  - Có thể edit bằng text editor hoặc Poedit

.mo (Machine Object):
  - File binary, compile từ .po
  - WordPress đọc file này (nhanh hơn .po)
  - Tạo tự động khi compile .po

.json (JavaScript translations):
  - Dùng cho i18n trong JavaScript/Gutenberg
  - Tạo bằng wp i18n make-json
```

## 2. PHP Translation Functions

### 2.1. Các hàm cơ bản

```php
<?php
/**
 * __() - Trả về string đã dịch (RETURN, không echo).
 * Dùng khi cần gán vào biến, truyền vào function.
 */
$title = __( 'Hello World', 'my-plugin' );
//          ^string gốc      ^text domain

$label = __( 'Settings', 'my-plugin' );
echo '<h1>' . esc_html( $label ) . '</h1>';

/**
 * _e() - Echo string đã dịch (ECHO trực tiếp).
 * Dùng trong template khi cần hiển thị ngay.
 */
_e( 'Hello World', 'my-plugin' );
// Tương đương: echo __( 'Hello World', 'my-plugin' );

/**
 * esc_html__() - Return + esc_html (an toàn cho HTML).
 * esc_html_e() - Echo + esc_html.
 * esc_attr__() - Return + esc_attr (an toàn cho attributes).
 * esc_attr_e() - Echo + esc_attr.
 */
echo '<h1>' . esc_html__( 'Page Title', 'my-plugin' ) . '</h1>';
echo '<input placeholder="' . esc_attr__( 'Search...', 'my-plugin' ) . '">';

// Trong template
?>
<h1><?php esc_html_e( 'Page Title', 'my-plugin' ); ?></h1>
<input placeholder="<?php esc_attr_e( 'Search...', 'my-plugin' ); ?>">
```

### 2.2. Pluralization

```php
<?php
/**
 * _n() - Pluralization (số ít/số nhiều).
 * Nhiều ngôn ngữ có nhiều hơn 2 dạng plural.
 */
$count = 5;
$message = sprintf(
    /* translators: %d: number of comments */
    _n(
        '%d comment',          // Singular (số ít)
        '%d comments',         // Plural (số nhiều)
        $count,                // Số lượng (quyết định dùng dạng nào)
        'my-plugin'            // Text domain
    ),
    $count
);
echo $message; // "5 comments"

// Ví dụ thực tế
$post_count = wp_count_posts()->publish;
printf(
    /* translators: %s: number of published posts */
    _n(
        'There is %s published post.',
        'There are %s published posts.',
        $post_count,
        'my-plugin'
    ),
    number_format_i18n( $post_count )
);

/**
 * _nx() - Pluralization + Context.
 */
printf(
    _nx(
        '%s item',              // Singular
        '%s items',             // Plural
        $count,                 // Count
        'cart items count',     // Context cho translator
        'my-plugin'             // Text domain
    ),
    $count
);
```

### 2.3. Context (Disambiguation)

```php
<?php
/**
 * _x() - Translation với context.
 * Dùng khi 1 từ tiếng Anh có nhiều nghĩa.
 *
 * Ví dụ: "Post" có thể là:
 *   - Bài viết (noun)
 *   - Đăng/Gửi (verb)
 *   - Chức vụ (position)
 */

// Cùng string "Post" nhưng context khác → dịch khác
$noun = _x( 'Post', 'noun: a blog post', 'my-plugin' );      // → "Bài viết"
$verb = _x( 'Post', 'verb: to publish', 'my-plugin' );        // → "Đăng"

// Ví dụ thực tế
$label_comment = _x( 'Comment', 'noun: user comment', 'my-plugin' );
$label_submit  = _x( 'Comment', 'verb: submit a comment', 'my-plugin' );

/**
 * _ex() - Echo version of _x().
 */
?>
<button><?php _ex( 'Post', 'verb: publish this post', 'my-plugin' ); ?></button>
<h2><?php _ex( 'Post', 'noun: blog post', 'my-plugin' ); ?></h2>

<?php
/**
 * esc_html_x() - Context + esc_html.
 * esc_attr_x() - Context + esc_attr.
 */
echo '<label>' . esc_html_x( 'Name', 'label for person name', 'my-plugin' ) . '</label>';
echo '<label>' . esc_html_x( 'Name', 'label for product name', 'my-plugin' ) . '</label>';
```

### 2.4. Translator Comments

```php
<?php
/**
 * Translator comments giúp dịch giả hiểu ngữ cảnh.
 * PHẢI ở dòng ngay TRƯỚC translation function.
 * Bắt đầu bằng: translators:
 */

/* translators: %s: user display name */
printf( __( 'Howdy, %s', 'my-plugin' ), $user->display_name );

/* translators: 1: date, 2: time */
printf(
    __( 'Published on %1$s at %2$s', 'my-plugin' ),
    get_the_date(),
    get_the_time()
);

/* translators: %d: number of items in cart */
printf(
    _n( '%d item in your cart', '%d items in your cart', $count, 'my-plugin' ),
    $count
);

// SSIS: Không sử dụng biến trong string
// ❌ SAI
__( "Welcome to $site_name", 'my-plugin' );

// ✅ ĐÚNG
sprintf( __( 'Welcome to %s', 'my-plugin' ), $site_name );
```

### 2.5. Những cách SAI và ĐÚNG

```php
<?php
// ❌ SAI: Không dùng biến trong __()
$key = 'hello';
__( $key, 'my-plugin' ); // Tools extract không tìm được string

// ✅ ĐÚNG
__( 'hello', 'my-plugin' );

// ❌ SAI: Nối string
__( 'Hello ' . $name, 'my-plugin' );

// ✅ ĐÚNG: Dùng sprintf
sprintf( __( 'Hello %s', 'my-plugin' ), $name );

// ❌ SAI: HTML trong translation string
__( '<strong>Bold text</strong> and more', 'my-plugin' );

// ✅ ĐÚNG: Tách HTML ra ngoài
'<strong>' . esc_html__( 'Bold text', 'my-plugin' ) . '</strong>' . esc_html__( ' and more', 'my-plugin' );

// Hoặc dùng wp_kses cho HTML đơn giản
$allowed = array( 'strong' => array(), 'em' => array(), 'a' => array( 'href' => array() ) );
echo wp_kses(
    __( '<strong>Bold text</strong> and <a href="%s">link</a>', 'my-plugin' ),
    $allowed
);

// ❌ SAI: Text domain không phải string literal
$domain = 'my-plugin';
__( 'Hello', $domain );

// ✅ ĐÚNG: Text domain phải là string literal
__( 'Hello', 'my-plugin' );

// ❌ SAI: Escape bên trong __()
__( esc_html( 'text' ), 'my-plugin' );

// ✅ ĐÚNG: Escape bên ngoài
esc_html( __( 'text', 'my-plugin' ) );
// Hoặc dùng esc_html__()
esc_html__( 'text', 'my-plugin' );
```

## 3. Load Text Domain

### 3.1. Plugin

```php
<?php
/**
 * Load text domain cho plugin.
 * Hook: init (hoặc plugins_loaded cho backward compat).
 */

// Cách 1: Standard (plugin từ WordPress.org)
function my_plugin_load_textdomain() {
    load_plugin_textdomain(
        'my-plugin',                                     // Text domain
        false,                                           // Deprecated param
        dirname( plugin_basename( __FILE__ ) ) . '/languages' // Relative path
    );
}
add_action( 'init', 'my_plugin_load_textdomain' );

// WordPress tìm file dịch theo thứ tự:
// 1. wp-content/languages/plugins/my-plugin-vi.mo  (user override)
// 2. wp-content/plugins/my-plugin/languages/my-plugin-vi.mo  (bundled)

/**
 * WordPress 6.7+: Auto-load translations.
 * Nếu plugin đã submit lên WordPress.org, translations TỰ ĐỘNG load.
 * Không cần gọi load_plugin_textdomain() nếu dùng translate.wordpress.org.
 *
 * Nhưng vẫn nên gọi để backward compat và self-hosted translations.
 */
```

### 3.2. Theme

```php
<?php
/**
 * Load text domain cho theme.
 * Hook: after_setup_theme
 */

function my_theme_setup() {
    load_theme_textdomain(
        'my-theme',
        get_template_directory() . '/languages'
    );
}
add_action( 'after_setup_theme', 'my_theme_setup' );

// WordPress tìm file dịch:
// 1. wp-content/languages/themes/my-theme-vi.mo  (user override)
// 2. wp-content/themes/my-theme/languages/my-theme-vi.mo  (bundled)

/**
 * Child theme: load text domain riêng.
 */
function my_child_theme_setup() {
    load_child_theme_textdomain(
        'my-child-theme',
        get_stylesheet_directory() . '/languages'
    );
}
add_action( 'after_setup_theme', 'my_child_theme_setup' );
```

### 3.3. Cấu trúc thư mục languages

```
my-plugin/
├── languages/
│   ├── my-plugin.pot             ← Template (source of truth)
│   ├── my-plugin-vi.po           ← Tiếng Việt (editable)
│   ├── my-plugin-vi.mo           ← Tiếng Việt (compiled)
│   ├── my-plugin-ja.po           ← Tiếng Nhật
│   ├── my-plugin-ja.mo
│   ├── my-plugin-vi-abc123.json  ← JS translations (Vietnamese)
│   └── my-plugin-ja-abc123.json  ← JS translations (Japanese)
```

## 4. Tạo file .pot với WP-CLI

```bash
# ── TẠO FILE .pot ────────────────────────────────────────────────

# Plugin
wp i18n make-pot wp-content/plugins/my-plugin wp-content/plugins/my-plugin/languages/my-plugin.pot

# Theme
wp i18n make-pot wp-content/themes/my-theme wp-content/themes/my-theme/languages/my-theme.pot

# Với options
wp i18n make-pot wp-content/plugins/my-plugin languages/my-plugin.pot \
    --domain=my-plugin \
    --exclude=node_modules,vendor,tests \
    --headers='{"Report-Msgid-Bugs-To":"https://example.com/support"}' \
    --file-comment="Copyright (C) 2024 My Company"

# Chỉ scan file PHP
wp i18n make-pot wp-content/plugins/my-plugin languages/my-plugin.pot \
    --include=*.php

# ── TẠO FILE .json CHO JAVASCRIPT ───────────────────────────────

# Từ .po file → tạo .json cho mỗi JS file
wp i18n make-json languages/ --no-purge

# Output: languages/my-plugin-vi-{hash}.json cho mỗi JS file
# Hash = md5 của relative path đến JS file

# ── CẬP NHẬT .po TỪ .pot MỚI ────────────────────────────────────

# Merge strings mới từ .pot vào .po hiện có
wp i18n update-po languages/my-plugin.pot languages/
```

## 5. Làm việc với .po và .mo

### 5.1. Tạo .po từ .pot

```bash
# Copy .pot thành .po và đặt tên theo locale
cp languages/my-plugin.pot languages/my-plugin-vi.po
# Locale codes: vi, ja, zh_CN, zh_TW, ko, fr_FR, de_DE, es_ES, pt_BR...
```

### 5.2. Dịch bằng Poedit (GUI tool)

```
1. Mở Poedit → File → Open → chọn .po file
2. Catalog → Properties:
   - Language: Vietnamese
   - Charset: UTF-8
   - Team: Your Name <email>
3. Dịch từng string
4. File → Save → tự động tạo .mo

Poedit Pro: hỗ trợ dịch tự động bằng AI
```

### 5.3. Ví dụ file .po đã dịch

```
# File: languages/my-plugin-vi.po

msgid ""
msgstr ""
"Project-Id-Version: My Plugin 1.0.0\n"
"Language: vi\n"
"MIME-Version: 1.0\n"
"Content-Type: text/plain; charset=UTF-8\n"
"Plural-Forms: nplurals=1; plural=0;\n"

#: src/Admin/Settings.php:45
msgid "Settings"
msgstr "Cài đặt"

#: src/Admin/Settings.php:67
msgid "Welcome, %s"
msgstr "Xin chào, %s"

#: src/Frontend/Widget.php:23
msgctxt "noun: blog post"
msgid "Post"
msgstr "Bài viết"

#: src/Frontend/Widget.php:30
msgctxt "verb: publish"
msgid "Post"
msgstr "Đăng"

#: src/Frontend/Widget.php:50
msgid "%d comment"
msgid_plural "%d comments"
msgstr[0] "%d bình luận"
```

### 5.4. Compile .po → .mo

```bash
# Dùng WP-CLI
wp i18n make-mo languages/

# Dùng msgfmt (GNU gettext)
msgfmt -o languages/my-plugin-vi.mo languages/my-plugin-vi.po

# Poedit tự động compile khi save
```

### 5.5. Loco Translate (WordPress Plugin)

```
Loco Translate plugin cho phép dịch trực tiếp trong WordPress admin:
  1. Install plugin Loco Translate
  2. Loco Translate → Plugins → chọn plugin
  3. New Language → Vietnamese

Ưu điểm: Không cần tools bên ngoài
```

## 6. JavaScript Translations

### 6.1. Đăng ký JS translations

```php
<?php
/**
 * wp_set_script_translations() - Load translations cho JS file.
 * WordPress 5.0+
 */

function my_plugin_enqueue_scripts() {
    wp_enqueue_script(
        'my-plugin-admin',
        plugins_url( 'build/admin.js', __FILE__ ),
        array( 'wp-i18n' ),  // QUAN TRỌNG: dependency wp-i18n
        '1.0.0',
        true
    );

    // Load translations cho script handle
    wp_set_script_translations(
        'my-plugin-admin',                                  // Script handle
        'my-plugin',                                        // Text domain
        plugin_dir_path( __FILE__ ) . 'languages'           // Path to .json files
    );
}
add_action( 'admin_enqueue_scripts', 'my_plugin_enqueue_scripts' );
```

## 7. Date, Time và Number Localization

```php
<?php
/**
 * WordPress tự động localize dates, times, numbers
 * theo ngôn ngữ trong Settings → General → Site Language.
 */

// ── DATE LOCALIZATION ───────────────────────────────────────────

// date_i18n() - Format date theo locale
echo date_i18n( 'F j, Y' );              // "Tháng Một 15, 2024" (vi)
echo date_i18n( 'l, F j, Y', $timestamp ); // "Thứ Hai, Tháng Một 15, 2024"

// wp_date() - WordPress 5.3+ (modern replacement)
echo wp_date( 'F j, Y' );                // Dùng timezone từ Settings
echo wp_date( 'F j, Y', $timestamp );    // Với custom timestamp

// get_the_date() - Cho posts
echo get_the_date( 'd/m/Y', $post_id );

// human_time_diff() - "5 phút trước", "2 giờ trước"
echo human_time_diff( get_the_time( 'U' ), current_time( 'timestamp' ) ) . ' trước';

// current_time() - Thời gian hiện tại theo timezone WP
$mysql_time = current_time( 'mysql' );     // 2024-01-15 10:30:00
$timestamp  = current_time( 'timestamp' ); // Unix timestamp (local)

// ── NUMBER LOCALIZATION ─────────────────────────────────────────

// number_format_i18n() - Format số theo locale
echo number_format_i18n( 1234567.89 );     // "1.234.567,89" (vi locale)
echo number_format_i18n( 1234567.89, 2 );  // "1.234.567,89"

// size_format() - Format file size
echo size_format( 1048576 );        // "1 MB"
echo size_format( 2621440 );        // "2,5 MB"

// ── CURRENCY (không built-in, cần custom) ───────────────────────

function my_format_currency( float $amount, string $currency = 'VND' ): string {
    $formatted = number_format_i18n( $amount, $currency === 'VND' ? 0 : 2 );

    return match ( $currency ) {
        'VND'  => $formatted . ' ₫',
        'USD'  => '$' . $formatted,
        'EUR'  => '€' . $formatted,
        'JPY'  => '¥' . $formatted,
        default => $formatted . ' ' . $currency,
    };
}

echo my_format_currency( 1500000, 'VND' ); // "1.500.000 ₫"
echo my_format_currency( 99.99, 'USD' );   // "$99.99"
```

## 8. RTL (Right-to-Left) Support

```php
<?php
/**
 * RTL languages: Arabic (ar), Hebrew (he), Persian/Farsi (fa), Urdu (ur)...
 * WordPress tự động detect RTL từ locale.
 */

// ── KIỂM TRA RTL ───────────────────────────────────────────────

if ( is_rtl() ) {
    // Hiện tại đang dùng ngôn ngữ RTL
    wp_enqueue_style( 'my-plugin-rtl', plugins_url( 'css/rtl.css', __FILE__ ) );
}

// body_class() tự động thêm class "rtl" khi là RTL language
// <body class="rtl">

// ── CSS CHO RTL ─────────────────────────────────────────────────

/*
 * File: css/style.css (LTR default)
 */
// .sidebar { float: left; margin-right: 20px; }
// .content { margin-left: 300px; }

/*
 * File: css/rtl.css (RTL override)
 */
// .sidebar { float: right; margin-right: 0; margin-left: 20px; }
// .content { margin-left: 0; margin-right: 300px; }

/**
 * Modern CSS: Dùng logical properties (không cần file RTL riêng).
 */
// .sidebar {
//     float: inline-start;              /* left in LTR, right in RTL */
//     margin-inline-end: 20px;          /* margin-right in LTR, margin-left in RTL */
// }
// .content {
//     margin-inline-start: 300px;       /* margin-left in LTR, margin-right in RTL */
// }
// .text {
```

```php
add_action( 'template_redirect', function() {
    if ( ! isset( $_POST['cfi_submit'] ) ) {
        return;
    }

    if ( ! wp_verify_nonce( $_POST['cfi_nonce'] ?? '', 'cfi_submit' ) ) {
        wp_die( esc_html__( 'Security check failed. Please try again.', 'contact-form-i18n' ) );
    }

    $name    = sanitize_text_field( $_POST['cfi_name'] ?? '' );
    $email   = sanitize_email( $_POST['cfi_email'] ?? '' );
    $subject = sanitize_text_field( $_POST['cfi_subject'] ?? 'general' );
    $message = sanitize_textarea_field( $_POST['cfi_message'] ?? '' );

    // Validate
    if ( empty( $name ) || empty( $email ) || empty( $message ) ) {
        // Error message
        add_action( 'wp_footer', function() {
            echo '<script>alert("' . esc_js( __( 'Please fill in all required fields.', 'contact-form-i18n' ) ) . '")</script>';
        } );
        return;
    }

    // Send email
    $admin_email = get_option( 'admin_email' );

    /* translators: %s: website name */
    $email_subject = sprintf(
        __( '[%s] New Contact Form Submission', 'contact-form-i18n' ),
        get_bloginfo( 'name' )
    );

    /* translators: 1: sender name, 2: sender email, 3: subject type, 4: message content */
    $email_body = sprintf(
        __( "Name: %1\$s\nEmail: %2\$s\nSubject: %3\$s\n\nMessage:\n%4\$s", 'contact-form-i18n' ),
        $name,
        $email,
        $subject,
        $message
    );

    $sent = wp_mail( $admin_email, $email_subject, $email_body, array(
        "Reply-To: {$name} <{$email}>",
    ) );

    if ( $sent ) {
        add_action( 'wp_footer', function() {
            echo '<script>alert("' . esc_js( __( 'Thank you! Your message has been sent successfully.', 'contact-form-i18n' ) ) . '")</script>';
        } );
    }
} );
```

## 11. Translation Checklist

```
Plugin/Theme Release Checklist:

□ Tất cả user-facing strings wrap bằng __(), _e(), esc_html__()...
□ Text domain nhất quán trong tất cả files
□ Text domain match với plugin/theme slug
□ Plugin header có "Text Domain:" và "Domain Path:"
□ load_plugin_textdomain() / load_theme_textdomain() trong init/after_setup_theme
□ Không dùng biến trong translation functions
□ Dùng sprintf() cho dynamic strings, không nối chuỗi
□ Translator comments cho strings có placeholders
□ Dùng _x() cho strings ambiguous
□ Dùng _n() cho pluralization
□ Escape output: esc_html__(), esc_attr__()
□ File .pot đã tạo bằng wp i18n make-pot
□ RTL support (CSS logical properties hoặc rtl.css)
□ JS translations: wp_set_script_translations()
□ JSON translation files tạo bằng wp i18n make-json
□ Dates dùng date_i18n() hoặc wp_date()
□ Numbers dùng number_format_i18n()
```

## 12. So sánh với Laravel Localization

| Tính năng | WordPress | Laravel |
|-----------|-----------|---------|
| **Format** | .po/.mo (GNU gettext) | .php arrays hoặc .json |
| **Load** | `load_plugin_textdomain()` | Auto-load từ `lang/` |
| **Basic** | `__('text', 'domain')` | `__('text')` hoặc `trans('file.key')` |
| **Echo** | `_e('text', 'domain')` | `{{ __('text') }}` (Blade) |
| **Plural** | `_n('1 item', '%d items', $n, 'domain')` | `trans_choice('1 item\|:count items', $n)` |
| **Context** | `_x('Post', 'noun', 'domain')` | Không có built-in |
| **Parameters** | `sprintf(__('Hello %s'), $name)` | `__('Hello :name', ['name' => $name])` |
| **JS** | `@wordpress/i18n` + JSON | `Lang.js` hoặc Inertia |
| **Generate** | `wp i18n make-pot` | `php artisan lang:publish` |
| **Compile** | .po → .mo (binary) | Không cần compile |
| **Tools** | Poedit, Loco Translate | Tay hoặc tools |
| **Platform** | translate.wordpress.org | Không có centralized |
| **RTL** | `is_rtl()`, auto `dir="rtl"` | Tự implement |
| **Date** | `date_i18n()`, `wp_date()` | `Carbon::translatedFormat()` |

### So sánh code

```php
<?php
// ── LARAVEL ─────────────────────────────────────────────────────

// lang/vi/messages.php
return [
    'welcome' => 'Xin chào, :name',
    'items'   => '{0} Không có item|{1} 1 item|[2,*] :count items',
];

// Sử dụng
echo __('messages.welcome', ['name' => 'John']);  // "Xin chào, John"
echo trans_choice('messages.items', 5, ['count' => 5]); // "5 items"

// Blade
@lang('messages.welcome', ['name' => $user->name])
{{ __('messages.welcome', ['name' => $user->name]) }}

// ── WORDPRESS ───────────────────────────────────────────────────

// Sử dụng (strings trong code, dịch trong .po files)
sprintf( __( 'Welcome, %s', 'my-plugin' ), 'John' ); // "Xin chào, John"
printf(
    _n( '%d item', '%d items', 5, 'my-plugin' ),
    5
); // "5 items"

// Template
esc_html_e( 'Welcome', 'my-plugin' );
printf( esc_html__( 'Welcome, %s', 'my-plugin' ), esc_html( $user->display_name ) );
```
